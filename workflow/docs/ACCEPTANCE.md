## 自动检查与图形检查

自动测试覆盖字段映射冲突、工作表歧义、多编码表格、CSV 公式转义、异常隔离和去重追踪、MEDLINE/RIS/XML、缓存损坏、向量错位、分词分块、API 重试与鉴权隔离、离线行为、锁和恢复、取消、阶段/最终产物篡改、结果打包，以及 UTF-8 JSONL 事件。

集成测试调用真实 BERTopic：72 条受控合成向量数据跑通全部阶段；另验证“全部离群且没有年份”会交付诊断结果，并对不适用的图说明原因。稀疏年份和零离群率有独立图形语义回归检查。最终结果为 **44 项通过**，Ruff 检查通过；验收证据写入本地 `.validation/test-results.xml`。

15 类真实样本静态图已逐类检查缩略图，并放大检查词云、长机构标签、时间趋势、词秩、质量诊断及桑基图。检查涉及标题、脚注、刻度、图例、中文显示、流量边界和数据口径；已修正零离群率负刻度及空年份连线问题。图的数值正确性另由独立计算检查，不以视觉检查替代。未来输入产生的新图仍需按实际内容审阅。

桌面桥测试验证 capabilities、错误传播、启动前取消及 worker 环境隔离，均已通过。真实 API 响应和本地模型加载采用受控替身测试；没有使用用户密钥做在线接口或本地权重下载验收。

## 安装与发布范围

Windows、Python 3.11.9 已执行源代码测试。另在 `.venv_workflow` 覆盖环境中安装 wheel，并从仓库外工作目录验证 CLI、依赖检查、结果核验及 Node 桌面桥。该环境使用 `--system-site-packages`，可复用已安装依赖，不能等同于空白机器安装验收。

发布物包含 wheel、源码分发、配置/事件 Schema、CLI/SDK、Node 桥、配置示例、接入文档、依赖版本快照、CycloneDX SBOM、SHA-256 和构建清单；ZIP 执行 CRC 检查。依赖清单反映本次构建环境，不能代替漏洞扫描、第三方许可证审查或适用于所有平台的哈希锁定依赖仓库。发布物不附带 Python、依赖二进制、模型权重、API 凭据或私有文献。
